# Repost Grid — iPhone prototype

Это статический прототип интерфейса. Он НЕ получает список репостов, НЕ читает cookies и НЕ удаляет видео.

## Как открыть на iPhone
1. Архив нужно разместить на статическом HTTPS-хостинге, чтобы сайт открывался по ссылке.
2. Открой ссылку в Safari.
3. Нажми «Поделиться» → «На экран Домой».

Важно: просто открыть HTML из ZIP или добавить локальный файл на экран Домой недостаточно для полноценной веб-службы. Из-за изоляции сайтов этот интерфейс не может использовать сессию TikTok из другой вкладки. Следующий этап — отдельная проверка работы через авторизованный контекст, без передачи пароля/cookies.
